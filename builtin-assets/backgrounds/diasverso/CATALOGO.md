# Biblioteca de backgrounds

Arquivos fornecidos pelo usuário a partir da pasta `Backgrounds` no Google Drive.
Todos os 48 arquivos usam o prefixo `background_` tanto no Drive quanto no
projeto. Use o nome exato, incluindo a extensão, no JSON. Todos aparecem no
seletor de backgrounds do editor.

Use `"background": {"color": "#182238"}` para cor sólida,
`"background": {"asset": "builtin://backgrounds/diasverso/background_amarelo.png"}`
para um arquivo desta coleção, ou `project://assets/fundo.png` para um fundo
particular do vídeo. Para vídeos curtos, inclua `"loop": true` se quiser
repeti-los até o fim da cena.
