# Skills do Content Lab

A entrada é contentlab-direcao. Módulos: contentlab-composicao, contentlab-motion, contentlab-cenas-tsx, contentlab-timeline-audio, contentlab-contrato e contentlab-revisao. A skill ZIP inclui os mesmos manuais gerados do site e a biblioteca scene-library com guias, exemplos e prévias. Perfis editoriais externos são opcionais e não fazem parte do padrão público.

Para escolher um preset, consulte a Galeria de cenas especiais e o manifesto antes de criar novo código. A instalação copia uma versão local para custom-scenes e não modifica o plano nem inicia render. TSX é código executável de origem confiável, sem sandbox.
